Installationsanleitung

Studien-Dashboard · Windows · Python 3.11 oder neuer

Das Dashboard zeigt den Studienfortschritt in einer grafischen Oberfläche. Es benötigt keine zusätzlichen Laufzeitpakete: Tkinter und SQLite gehören zur Python-Standardbibliothek.

1. Voraussetzungen prüfen

Installieren Sie Python 3.11 oder neuer von python.org. Achten Sie im Installer darauf, Tcl/Tk und IDLE mitzuinstallieren. Installieren Sie Git, falls es noch nicht vorhanden ist.

2. Repository herunterladen

Öffnen Sie PowerShell und führen Sie die folgenden Befehle aus. Das Repository wird in den aktuellen Ordner geklont. 

git clone https://github.com/mariusburkhardt/Dashboard.git
cd .\Dashboard\Dashboard

3. Installation prüfen und starten

python --version
python -m tkinter
python -m src.main

Der Versionsbefehl muss Python 3.11 oder neuer anzeigen. Der Tkinter-Test öffnet ein kleines Testfenster; schließen Sie es wieder. Der letzte Befehl startet das Studien-Dashboard.

Daten und erneuter Start

Beim ersten Start legt die Anwendung in Dashboard\data eine leere SQLite-Datenbank an. Klicken Sie auf Kerndaten anpassen, um Ihren Namen, Studiengang, Studienstart und die Zielwerte einzutragen. Die Angaben bleiben bei späteren Starts gespeichert.

Zum Ausprobieren können Sie stattdessen über Importieren die Datei Dashboard\examples\beispielstudiengang.json auswählen. Der Datensatz enthält ausdrücklich gekennzeichnete Beispieldaten.

Tests (optional)

Zum Ausführen der automatisierten Tests installieren Sie pytest:

python -m pip install -r requirements.txt
python -m pytest -q

Hinweis: Starten Sie src\main.py nicht mit „Run Code“ als einzelne Datei. Verwenden Sie im Ordner Dashboard den Modulstart python -m src.main; so werden die Paketimporte korrekt aufgelöst.
